Methods, sources and downloads
  • Forecasts and MRMS use the same 0.25° verification locations and accumulation times. Contour shading interpolates only for display; scores use original samples.
  • Mapped windows were selected using observations. Overlapping windows and nearby points are dependent; storm results do not establish a general model ranking.
  • CRPS uses the corrected zero-mass formula. Training used the earlier objective; these frozen models were scored without retraining.

A threshold event means rainfall strictly exceeds the selected amount. Raw HRRR is a deterministic forecast. County lines and town labels provide geographic context.
