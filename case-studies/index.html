Comparison scope: the Hill Country reference is the controlled 0.25° ANN; the Edouard reference is the operational 0.25° ANN. The GNN uses a 0.25° graph. Hill Country's ANN and GNN training archives differ, so this comparison does not isolate architecture alone.

Averages weight each available window equally within each duration. All windows within a storm use the same number of regional points. Windows overlap, and nearby points are dependent; differences here are descriptive, without significance claims. These case results do not establish a general operational winner.

Scope of this case

Keep the target and forecast provenance explicit.

Each accumulation window is scored separately. Overlapping windows and nearby locations are dependent; this page makes no single-storm significance claims. Filled contours interpolate only for display between common 0.25° samples. Missing locations remain masked. Scores, binary exceedances and local errors use original sample values.

Model choices list only models present in that window’s scored export. A native predictor grid does not make the common 0.25° verification target a native 3-km observation grid.

County and parish lines and municipal centroids: U.S. Census Bureau TIGERweb. Town labels are geographic context, not rain gauges.
